# Project Overview

- Proyecto full-stack de dashboard financiero.
- Backend: FastAPI (`backend/app/main.py`, `backend/app/routes.py`).
- Frontend: React + TypeScript + Vite (`frontend/src`).
- Orquestación local: `docker-compose.yml`.
- Objetivo funcional: mostrar KPIs (income, outcome, profit), evolución mensual y métricas derivadas.
